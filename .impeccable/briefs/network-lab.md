OWN-WORLD: Inherit seasonal exhibition ground, ink, controls and font roles. Three named, color-distinct routes, geometric destination shapes, actual SVG routes and state-driven trains; no imported game artwork or physical-material imitation.

FORM: User-pinned transit-network playfield inside the incumbent Labs section; seed not run because this is a specified local extension. No approved comp or raster asset is needed for runtime graph geometry.
