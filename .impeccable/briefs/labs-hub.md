# 实验室迁移与自主塔防

用户要求统一“xx实验室”，完整提供造物图鉴/公式以便改写扩充，优化有序性 UI，将自主性改为参考植物大战僵尸的轻量塔防，并将所有游戏移到顶部独立板块。局部扩展，保留既有季节展厅、字体和内容，不创建替代视觉世界，不再开展 comp 或 seed 流程。

THESIS: 把系统原理变成可以反复试的三种操作。独立实验室入口承载玩法，学术首页恢复作者与成果的重点。

OWN-WORLD: 沿用季节昼夜 ink/panel/field/accent/line、Research Display 和既有正文。设计方差6、动效5、密度5。网络与三路战场是可操作几何，原创守卫/扰动为一套 crisp SVG；没有新字体、位图、音效、依赖和外部服务。

STORY: 顶部 Labs → 选造物/有序/自主 → 操作、观察、重试 → 各自本机进度。造物完整编辑稿提供稳定ID、100项元素、101配方、图形、双语解释与修改意见；修改文件不会自动发布，交回再审核同步。有序增加顺逆转向与断口标记、精炼实际读数。自主三路六列，前五列布阵，四种守卫各承担供能/攻击/阻挡/支援，扰动三种，六关逐波加压；波间暂停、升级/回收、逐拍、双速、收藏/确认清空形成完整循环。旧首页锚点及概念暗门导向新板块。

FIRST VIEWPORT: 简洁实验室标题与三个真实入口；默认展开造物，带锚点则直接打开对应实验室，其他收起。桌面有序大网络加诊断操作栏，手机棋盘先行；自主的能量/防线/波次、四守卫选择、战场、运行控件构成工作流。战场可主动定位，手机六列维持可点击宽度，长说明在下方原生展开区。

FORM: 造物合成短动画保持原实现；有序管线180ms旋转与一次实际BFS试流；自主有限波次以显式时钟推进，移动/弹丸/供能与响应全部来自模拟状态。关闭/离屏/隐藏/失焦/打印/偏好变化暂停，重新展开不自启。减少动效抑制视觉过渡，逐拍可完成所有演算。无闲置循环。

FINISH: finish review, bounded verdict if needed, incumbent design documentation comparison, production build and meaningful engine/browser checks before push.

参考 EA 官方说明中购买/安放守卫、资源供给及分波防守的玩法：[Plants vs. Zombies Readme](https://akamai.cdn.ea.com/eadownloads/u/f/manuals/GAME-PVZ/en_US_readme.html)。不使用其角色、图像、名称或代码。自主性落点是守卫根据局部状态蓄能、再生、修复和减速，不把普通攻击包装为原理全貌。
