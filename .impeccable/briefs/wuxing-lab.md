# 造物实验室 / Wuxing Lab

首页局部扩展，Experience / Operate。用户已确定 Doodle God 式联系发现、阴阳开篇、首版 40 元素，随后用户授权连续扩展到约 100 元素、每项独特示意形状、短合成动画，以及始终可回看的图鉴和公式。玩法结构参考，路线、符号和文字独立创作。第一批 40 包含阴阳两项起点；最终版 100 个元素、101 条公式。第一批通过引擎与可达性检查后继续扩展，最终 UI 一并验收。数据集中维护，允许后续扩展。

## Direction contract

THESIS: 从两个起点长出关系网络。每个发现可继续组合，图鉴和公式解释来路；采用原生展开区，不用打断阅读的游戏弹窗。

OWN-WORLD: 继承主页四季昼夜令牌、Research Display 与现有正文。简洁等宽线条 SVG 图形是元素的身份，圆形实验槽、干净留白与有序收藏板组织操作。方差 6、动效 5、密度 4；原生 CSS / SVG / Web Animations，无新库。

STORY: 选两项或拖放，合成并收藏；失败时可按需取提示；图鉴阅读、公式复现、保存图鉴、本机持久进度与显式重置均可达。配方说明区分象意、简化造物过程和系统联系，不将其写成化学方程或医疗指导。

FIRST VIEWPORT: 首页研究索引之后为可展开的完整实验区。标题旁出现阴阳两枚独立图形及展开动作；展开后左为两个输入圆槽和中央结果，右为已发现元素。顶端三个原生按钮切换实验台、图鉴、公式。手机改为纵向文档流，控件不依赖悬停。

FORM: 用户明确指定的二元组合玩法，局部扩展，无抽签或新视觉世界。焦点动作为两枚输入图形向中心汇聚、结果线形显现；持续不到一秒。无常驻循环；关闭动效、系统减少动效、后台、离屏和关闭实验区时取消动画，结果与操作仍完整。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Finished implementation record

- 数据为 100 个元素、101 条公式；五组分类、两项起点、全部独立 SVG 符号集中维护在 `_data/wuxing_lab.json` 与 `_includes/wuxing-symbols.svg`。符号是原创矢量，无新增位图或位图来源记录。
- 首页原生展开区有实验台、图鉴、公式三个按钮视图。点选、键盘、桌面拖放可组合；已发现元素可按中英文名称搜索和分类。图鉴展示描述与已知来路，公式可放回实验台；未发现公式需显式显示，前置元素不足时不能载入。提示按需提供。
- 延用季节/昼夜的 ink、panel、field、accent、line 与 button-ink，以及 Research Display / 原正文字体。圆槽、汇聚线与收藏格为局部组件；桌面双栏，650px 以下自然纵排，360px 以下收藏与图鉴三列。图鉴详情和实验台返回均滚动到可见位置并转移焦点。
- 合成事件为 460ms 汇聚、550ms 结果显现，无闲置循环。关闭区块、切换视图、后台/失焦、结果离屏、专注、打印、手动关闭动效与系统减少动效均取消或省略。配方明确区分文化意象、简化造物、系统联系，不承诺化学或医疗事实。
- 仅已发现公式 ID 写入本机 `wuxing-lab-progress-v1`，恢复时按前置可达性校验；支持当前语言的文字图鉴/公式下载和显式二次确认清空。持久收藏与长夏等页面内存彩蛋、未持久化的合作草稿互相独立。
- `.impeccable/review/wuxing-finish-review.md` 的 ship 仅对三项原问题的修复复核负责：图鉴详情可见及焦点、返回实验台可见及焦点、太极两点对比。截图为视口切片，完整路线/恢复/导出观察来自父代理；本次系统文档更新不新增检测器、构建、浏览器或整站验收结论。
