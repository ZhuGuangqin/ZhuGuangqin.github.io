# 三个候选实验室 demo

2026-10-09，按作者“先做3个demo我试一下”制作；先本机比较，不推送GitHub，不预先确定剩余两个原理的最终玩法。入口为 `/labs/demos/`，也可从五个正式实验室页的试玩链接进入。

| 原型 | 核心操作 | 当前内容 |
| --- | --- | --- |
| 生息 / Life | 点亮或熄灭格子，运行或逐代观察 | 三枚6×6种子：心跳、移动、双生节律；每题1–2格编辑额度，8代有限演化；可选线索与下一题 |
| 灵机 / Agency | 开关三条内部回应，试跑或逐步观察 | 一张6×5地图、两枚种子；补能、绕障、携种回巢实际影响路径和结果；最多64步 |
| 观象 / Perspective | 拉近/拉远，拖图或选图后点窗口 | 三幅初始叶片相同、全景条件不同的上下文题；雨云、日光、开窗改变实际水/光条件；撤回、重看、下一幅 |

生息使用同时更新的B3/S23规则，网格外为空；展示内在局部规则形成整体行为，不代表自主性的全部内涵。灵机的补能条件比较当前余量与回巢路径，绕行使用真实障碍路径，回巢规则决定送种。观象借鉴尺度与图景操作，不复用Gorogoa画作；图形是原创的功能模型图，整体状态决定相同动作的效果，不用固定成功脚本代替运行。

本页不读写存储、账号或外部服务；三项进度只在当前文档，刷新重来，五个正式实验室的成绩独立。中英文由主站切换，浅/深主题继承四季色板。生息支持方向键、Enter/Space；观象提供原生选图再点窗口的拖放替代。关闭动效后生命/机器人自动运行按钮禁用，逐步推演保留，图景操作保持静态结果。切换实验、后台、失焦、离屏、打印、Escape与偏好变化暂停正在运行的模型，返回不自启。

新增6项有意义的模型测试，连同49项既有回归共55项通过；检查了真实生命规则、每题可解且初始种子未达目标、机器人每条规则对结果的影响与能量边界、三个场景的不同解法、错误动作和有限试次。语法、差异、预览与safe构建通过，三个新资源仅在demo路由加载。

实际浏览器完成心跳自动演化，滑翔种子方向键/Enter编辑与8次逐拍成功；机器人关闭补能时19步没电、送回一枚，开启后逐步完成两枚。原生鼠标拖雨云到A成功，B使用雨云失败、撤回后日光成功，C开窗成功；手机点放与Enter替代可用。1280×989、390×950与319×850定向检查，中英/明暗与手动关闭动效有画面，319/390无横向溢出，手机阅读工具进入文档流。实物触屏、OS减少动效设置、读屏器和完整季节矩阵未实测。

证据在 `.impeccable/review/lab-demos/`：10张声明范围的视口切片、QA及一次检测记录，Agency窄屏规则另有补充图。设计系统仍为现有展厅，本轮保留DESIGN.md与sidecar，局部图形和尺寸不升级为全站令牌。

独立完成复核结论为 ship，无材料性修复；结论限定于三个候选 demo、所检视口与操作记录。独立文档复核结论为 No changes / evidence checked，DESIGN.md 与 `.impeccable/design.json` 保持原样；既有文档的造物数量及旧实验室归属漂移仅记录，未在本轮扩展中提升为规范。当前交付为本地试玩，未提交或推送。
