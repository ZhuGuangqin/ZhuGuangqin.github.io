# 主页交互与设计说明

本次在 Academic Pages / Jekyll 结构中增添交互。原详情地址与公开状态保留；简历栏目改名为「了解我 / Know Me」，继续使用 `/cv/`，保留 `/resume` 跳转。书目信息按本人补充更新。

## 使用方法

- 四时主题：点击春、夏、秋、冬，切换全站背景、文字、面板与控件色板；浅色、夜间各四组，跨页和刷新保留普通四季选择。
- 首页作者：首屏直接展示原头像、祝广钦 / Zhu Guangqin、中医基础理论博士研究生身份、北京中医药大学院校信息和「了解我的学术之路」入口。中文版含中医学院；英文保留当前大学名称。手机先展示作者，再展示研究标题。
- 同一片天穹：半透明球面融入首屏背景，绕页面中轴缓慢转动。昼间为春柳细雨、夏日层叠荷花、秋日扇形银杏与流云、冬日雪与冰晶；夜间为二十八宿与弧形星轨，不再另占顶部星图区块。
- 夜间二十八宿：球面正面可见数量随轮转及屏幕变化；桌面、手机选择器均含全部 28 宿，可将任意一宿带到正面并暂留。始终是传统四象，每象七宿。星位和连线是文化艺术编排，不是实时天象。
- 长夏彩蛋：首页默认隐藏。长按「夏」1.5 秒，或依次点击「春→夏→秋→冬」，任一条件都可解锁；「长夏 / Late summer」加入夏与秋之间，首屏和阅读工具菜单同步出现，并切到禾穗、露珠与水汽场景。键盘可依次激活四季，也可长按夏按钮的 Enter / 空格。移动超过 12px、移出、取消、失焦或切到后台会中断长按。
- 彩蛋寿命：只存在于当前页面内存。解锁后标题同步从“在四时变化中”变为“在五季变化中”，英文同步为“through the five seasons”。切换普通季节、中英文与昼夜仍保留；刷新或新文档重新隐藏，标题恢复原文，恢复最近一次普通四季选择。长夏及解锁标记不写入本地存储。长夏夜间仍使用原四象 28 宿，不增加第五象。
- 论文书架：封面可取阅，面板含原文、PDF、引用和原始条目入口。可以切换紧凑列表；真实期刊封面、本人提供的著作封面、主题创作、著作资料卡分别标明来源。
- 全站搜索：顶部搜索按钮、右下角工具条或 `⌘ K / Ctrl K` 打开。可搜中文、英文标题、作者、期刊、内容与年份。方向键选择结果，回车打开，Esc 关闭。
- 研究主题入口：点击首页的研究主题，直接检索相关内容。
- 论文筛选：关键词、成果类型、年份和全文 PDF 条件可以组合使用。条件写入网址，复制当前地址即可分享相同筛选结果。
- 引用与邮箱：一键复制；引用使用原条目中的 `citation`，只移除 HTML 格式，不改写作者或书目信息。
- 目录：根据当前页面、语言和筛选结果生成。页面有两个以上章节时显示。
- 专注：隐藏首屏和个人侧栏，扩大正文阅读区域；再次点击退出。偏好在本机保存。
- 动效：可手动关闭。操作系统开启“减少动态效果”时，优先遵循系统设置。

## 视觉约定

主体页面是四时现代学术展厅，春青绿、夏暖朱、秋赭金、冬冰蓝；长夏新增一对经授权的青灰土色昼夜配色，沿用同一套背景、面板、文字、强调色和线条语义。天穹与研究索引围绕真实公开资料组织。天穹属于艺术表达，主题检索是文字匹配，不宣称医学机制或文献语义模型。

首屏保持本地宋体标题与平台无衬线正文。桌面为作者、研究论述、季节控件三列；1100px 以下作者先成为整行，600px 以下自然排成一列。319px 窄屏的季节控件继续向下滚动可达，首屏高度不强行压缩文字。9px 英文季名、10px 天穹说明与 11px 辅助文字是局部图景标注；正文不使用这些尺寸。长夏解锁后的英文五季按钮使用 11px，完整保留名称。

「了解我」使用独立的银白、纸白、黄黑线条艺术。昼间以墨色文字和线条保证可读，夜间使用银白；季节改变强调色。图形是原创参数化艺术，不是科研模型。

## 了解我的空间叙事

1. BUCM / 祝广钦 / 中医系统论极简标志短暂绘制，有跳过与超时释放；减少动效时直接进入。
2. 立体 SVG 线场随时间、指针与脉冲变化。2017、2022、2024 按钮切换波面、环面、结状结构，同步显示真实求学阶段。
3. 七块学术坐标保持平面，随原生下滑从上向下揭开；停下阅读时全部展开，不倾斜或透视旋转。桌面四列按文字高度排布，系统块占两列两行，方向与 BUCM 各跨两列；手机为两列，始终正常向下阅读。屏幕较矮或英文内容较高时自动改为正常文档流，完整保留研究方向、公开论文数、已有 CNKI 记录、参与的 NSFC 项目、著作与求学说明。
4. 原生向下滚动带动横向经历长卷；也能用前后按钮和方向键浏览教育、会议与教学记录。
5. 作品通道自动汇集公开成果，封面由远及近漂流。点选或横向拖取可读详情；关闭后碎片溶解并返回原封面。可暂停、通过选择器取阅，也可直接进入成果列表。
6. SINCE 1998 明确表达出生年份；末尾提供动态联系区、复制邮箱、GitHub、重播开场与回到开篇。

完整履历保存在原生展开区。关闭动效、系统减少动效或专注模式下，长距离固定场景改为线性阅读；打印时展开全部记录。没有滚轮或触屏滚动劫持。连续绘制在离屏、标签页隐藏和打印时暂停。

Taste Skill 的设计读法为“面向同行的学术个人主页，学术出版气质与四时几何动效相结合”；取设计变化 6、动效强度 5、信息密度 4。Impeccable 用于动效、可用性与细节审查。本次保留既有事实文字，未按营销网站的文字精简规则删改学术内容。

首页标题使用本地的 Noto Serif SC / 思源宋体子集，许可见 `assets/fonts/research-display-LICENSE.txt`。若修改首页标题，要重新生成该字体子集或换用覆盖新文字的字体；缺失字符仍会使用后备字体。

搜索索引在 Jekyll 构建时自动生成，只收录公开页面和可发布的集合条目。`published: false` 的内容不会进入索引，也不会进入成果筛选计数。新增论文、项目等条目后正常构建即可，不需要手动维护搜索清单。

动效与交互使用原生 CSS/JavaScript，无额外前端框架。搜索索引只在首次打开搜索时加载；球面在离屏、标签页隐藏、专注和打印时暂停连续绘制，手动关闭或系统减少动效时保留静态图景。切换昼夜或季节的 0.65 秒交叠仅在允许动效时运行；原生文档滚动不受拦截。没有 JavaScript 或画布不可用时保留静态球面后备图及原页面、完整成果列表。球面样式和脚本只在首页加载；旧独立星图 CSS 不是当前渲染行为。

本轮 UI 的限定范围验收为 ship，记录在 `.impeccable/review/sky-finish-review.md`，浏览器与构建记录在 `sky-qa.json`。顺序解锁、中英文/昼夜保持、刷新隐藏及手动暂停有浏览器记录；长按阈值与取消路径使用实际脚本加模拟 DOM/计时器验证，不宣称实机触屏时长测试。减少动效、后台、离屏与专注路径有源码检查，不宣称已做操作系统减少动效模拟。当前截图清单及尺寸见《设计验收简报》末节。

本次同时将侧栏改为正文范围内的粘性定位，将页脚放回正常文档流，防止遮挡首屏与正文。导航的折叠菜单只绑定直接子级菜单按钮，避免新增搜索、语言和主题按钮误触折叠逻辑；宽屏恢复栏目时只插到第一个固定按钮前，避免向多个目标插入而复制栏目。
