## 2026-10-10 试玩反馈后的扩展

本轮仍为本机候选，不推送。三款统一使用原生结算对话框：方向、空格、Escape、背景点击均不退出；初始焦点在标题，Enter 不会误触重试。明确关闭后，原场地和结算都保留，可通过「查看结算」重新打开。只有主动重试或换局才清空这一局。

吞纳新增定量竞速（2000 / 3500 / 5500，240 / 330 / 420秒）、限时竞分（90 / 150 / 210秒）、无尽生长。1600×1200地图在180 / 400 / 900 / 1800体量逐级扩大视野；常规动效下平滑过渡，简化动效下直接切换。转向采用较快的目标速度跟随，松手保留滑行。普通、富养、6秒护盾、7秒加速、7秒毒性养分及尖刺各有形状区别。护盾抑制毒性和碰撞损耗。对手取养成长，按追逐、逃避、短冲、绕圈等行为行动；开局7秒不主动追逐。160体量可分身，8秒后靠近归并，两部分各自计算吞纳大小。地图提示周期性富养区域。

自生新增潮汐生存 / 守护核心；环卫 / 共振 / 飞针三个起始流派；九类三级结构和五组二级配对（护生环、蔓延、回生、针雨、生生林）。高储备（≥65）每7秒形成一层护卫，最多三层；受击花费12储备，伤害降至28%。调息1.6秒恢复储备并停步停攻，冷却18秒，可用急行取消。成长每局两次换组；精英补给另有修复、收取养分并增幅、削弱来袭并补护卫三选一。随机取养点、远程体、分裂体、终潮首领增加决策；180 / 240 / 300秒存活目标并须化解终潮首领，最多45秒宽限。数值是原创游戏意象，不作医学模拟。

合璧新增同心踏行，保留原环体穿行。双端交替落脚，另一端作为支撑；普通步范围185，弹簧增至245。18 / 26 / 34段地形，4 / 3 / 2次机会；稳固、横移、起伏、易碎（2.8秒）、弹簧台、摆动障碍、风向、星点与每六段检查点。落空回到检查点；两脚都到终点才完成。原地反复落脚不能刷分。同心踏行为简化的支撑关系规则，未采用完整刚体物理。
