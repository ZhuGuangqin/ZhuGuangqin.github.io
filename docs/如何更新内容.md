## 一、两种改法，挑一种就行

### 方式 A：在 GitHub 网页上直接改（推荐，零安装）

适合改错别字、改一句话、加一条论文。

1. 打开仓库，进到要改的文件
2. 点右上角的**铅笔图标** ✏️
3. 改完拉到最下面，点 **Commit changes**
4. 等 1–2 分钟，刷新 https://zhuguangqin.github.io 就能看到

**删文件**：进到该文件，点右上角**垃圾桶图标** 🗑 → Commit changes。

**加文件**：进到对应目录，点 **Add file → Create new file**，文件名和内容照抄下面的模板。

## 二、想改什么 → 改哪个文件

| 我想改… | 改这个文件 |
| --- | --- |
| **首页**自我介绍、研究方向、教育背景、联系方式 | `_pages/about.md` |
| **网页简历 CV** 的教育背景、项目、荣誉、技能 | `_pages/cv.md` |
| **顶部导航栏**（论文/学术会议/教学/科研项目/博客/简历） | `_data/navigation.yml` |
| **站点标题、侧栏名字/简介/邮箱/GitHub、配色** | `_config.yml` |
| **头像** | `images/profile.png`（直接覆盖同名文件） |
| **论文 / 著作** | `_publications/` 目录 |
| **学术会议** | `_talks/` 目录 |
| **教学 / 教改项目** | `_teaching/` 目录 |
| **科研项目** | `_portfolio/` 目录 |
| **博客文章** | `_posts/` 目录 |
| **论文 PDF 附件** | `files/` 目录（放进去后要在论文里写 `paperurl`） |
| **各栏目页面的标题**（如「论文」两个字） | `_pages/publications.html` 里的 `title:` |
| **侧栏「Follow」按钮、页脚** | `_includes/` 目录（模板代码，一般不用动） |

### 三个自动生成的地方，不用手写

- 「论文」页按 `category` **自动分组**显示 `_publications/` 全部条目
- 「学术会议」「教学」「科研项目」页分别是 `_talks/`、`_teaching/`、`_portfolio/` 的列表
- **CV 页的「论文」「学术会议」「教学」三节是自动从上面目录抓取的** —— 你加一篇论文，CV 里也会自动出现，不用改两遍

> 注意：CV 页里的**「科研与教学研究项目」「荣誉奖励」「专业技能」是手写的**，加项目后要自己去 `_pages/cv.md` 补一行。

## 三、三种操作怎么做

### ① 改一条内容

找到文件，改对应字段即可。比如把某篇论文的期刊名改掉：

```yaml
venue: '环球中医药'        # ← 改这里
```

### ② 删一条内容

**直接删掉那个 `.md` 文件**，对应的列表项、详情页、CV 里的条目会一起消失。

### ③ 加一条内容

在对应目录新建一个 `.md` 文件。**最省事的办法是复制一个现有的同类文件**，然后改里面的内容。
关键要求：**`permalink` 必须和别人不一样**。

#### 加一篇论文 / 著作 → `_publications/xxx.md`

```markdown
---
title: '论文标题'
collection: 'publications'
category: 'manuscripts'          # manuscripts=期刊论文 / books=著作教材 / conferences=会议论文
permalink: '/publication/2027-给个短名'   # ← 必须唯一，改了这句网址就变了
date: 2027-03-01                 # YYYY-MM-DD，第 1 位是最新；页面上只显示年份
venue: '环球中医药'
citation: '祝广钦, 等. 论文标题[J]. <i>环球中医药</i>, 2027, 18(3): 100-105.'
---

这里写点介绍，会显示在列表项里。
```

#### 加一次学术会议 → `_talks/xxx.md`

```markdown
---
title: '报告的题目'
collection: 'talks'
type: '口头汇报'                  # 或「国际会议壁报」
permalink: '/talks/2027-给个短名'
date: 2027-05-20                 # 这一项**会显示出来**；不知道就整行删掉，页面就不显示日期
venue: '会议名称'
location: '举办城市'              # 可不填
---

一句话说明。
```

#### 加一个科研项目 → `_portfolio/xxx.md`

```markdown
---
title: '项目名称'
collection: 'portfolio'
permalink: '/portfolio/2027-给个短名'
date: 2027-01-01
venue: '国家自然科学基金'          # 项目来源，会显示出来
excerpt: '一句话摘要'
---

项目详情：承担什么工作、排名第几。
```

#### 加一项教学 / 教改 → `_teaching/xxx.md`

```markdown
---
title: '课程或项目名称'
collection: 'teaching'
type: '教学研究项目（校级教改项目）'
permalink: '/teaching/2027-给个短名'
date: 2027-02-01
venue: '北京中医药大学'
location: ''
---

做了什么。
```

#### 加一篇博客 → `_posts/2027-05-20-短名.md`

**博客的文件名必须以 `年-月-日-` 开头**，这是 Jekyll 的硬性要求（其他目录没有这个要求）。

```markdown
---
title: "文章标题"
date: 2027-05-20
permalink: /posts/2027/05/short-name/
tags:
  - 随笔
---

正文用 Markdown 写。
```

## 四、四条容易踩的坑

1. **`permalink` 撞车** —— 两个文件写了同一个 `permalink`，后构建的会覆盖前一个，页面会莫名少一条。**新加条目一定换个短名。**
2. **`date` 决定排序** —— 列表是**从新到旧**排的。日期写错，条目就跑到列表末尾去了。
3. **`category` 只能是三个固定值** —— `books` / `manuscripts` / `conferences`。写了别的值，那条**不会出现在「论文」页上**（因为页面按这三个分组渲染）。
4. **YAML 里的中文引号** —— `title:` 后面如果内容里有引号，建议整体用**单引号**包起来，里面的单引号写成两个（`''`）。照抄现有文件的写法最保险。

## 五、常见任务速查

| 任务 | 做法 |
| --- | --- |
| **换头像** | 把新照片重命名为 `profile.png` 覆盖 `images/profile.png`（正方形，建议 ≥400×400） |
| **改邮箱** | `_config.yml` 里 `author:` 段的 `email:` |
| **加 Google Scholar** | `_config.yml` 里 `author:` 段的 `googlescholar:` 填上主页 URL，侧栏自动出图标 |
| **改导航栏文字/顺序** | `_data/navigation.yml`，顺序即显示顺序；删掉某一项就从导航消失 |
| **换配色** | `_config.yml` 里 `site_theme:`，可选 `default` / `air` / `sunrise` / `mint` / `dirt` / `contrast` |
| **给论文加下载链接** | 把 PDF 放进 `files/`，然后在论文的 front matter 加一行 `paperurl: '/files/文件名.pdf'` |
| **暂停某一栏** | 从 `_data/navigation.yml` 里删掉那一项即可（页面本身还在，只是导航不显示） |
| **补会议日期** | 在对应 `_talks/*.md` 里加一行 `date: 2025-11-01` |

## 六、出问题了怎么办

**先看构建有没有报错**：<https://github.com/ZhuGuangqin/ZhuGuangqin.github.io/actions>
（黄色=正在构建，绿色=成功，红色=失败，点进去能看到具体哪一行出错）

**改坏了想回退**：GitHub 上每一次提交都有记录。进仓库 → **Commits** → 找到改坏之前的那次 →
点 **Browse files** → 逐个文件把内容粘回去，或者本地用 `git revert`。

**YAML 格式检查**：如果站点整个变成白页或列表空了，八成是某个 `.md` 的 front matter 写坏了
（缩进、少了冒号、引号不配对）。挨个检查最近改的那几个文件。
