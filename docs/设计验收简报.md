# 本次设计方向与验收范围

## 用户反馈与本次要求
原反馈：春夏秋冬仅改变个别文字，整页几乎看不出变化。要求夜间顶部加入二十八宿；论文以当期期刊封面建立类似取下书架刊物的交互；其他板块建立有趣的联系；具有现代艺术和个性，但保留学术基础；突出系统论与自动化；最重要的是便捷。补充授权：找不到当期期刊封面时，生成符合论文主题的封面。

## 方向合同
- 现代学术展厅，温和的纸材、雕塑与几何感；不改变已有事实与导航结构。
- 春青绿、夏暖朱、秋赭金、冬冰蓝；每季浅色与夜间各一组完整色板。
- 一处主导的物理交互：期刊从书架取阅，快速进入有封面、原文摘要、PDF、引用的阅读面板；保留紧凑列表。
- 二十八宿按四象分组的文化示意图。桌面同时展示 28 宿；手机显示当前七宿，以四象按钮切换。星位与连线为艺术编排。
- 自动研究索引从现有公开内容计算相关论文与项目，显示真实匹配数。分类为主题文字检索，不宣称因果关系或文献相似度模型。
- 项目与教学原文以可展开档案呈现，会议原列表加入时间轴。
- 动效可关闭，系统减少动效优先；所有交互有键盘及触屏路径；首屏不等待动效。

## 简历第一版历史（已被最新方向替代，不作为最终视觉验收）
用户认可其他页面当前效果，明确要求简历页完全转变风格：前沿艺术、大胆、花哨动效、SVG 立体感、世界性设计。
- 方向：动态个人履历，以黑白与荧光黄、Space Grotesk / Noto Sans SC 本地字体、参数化 Möbius 空间带构成独立艺术页面；不改其他路由视觉系统。
- 图形为数学几何艺术，不是科研机制示意。学习阶段按钮选择 2017 / 2022 / 2024，同时重构旋转角度和比例，显示真实阶段；鼠标视差、缓慢悬浮、桌面滚动离场构成一个主导空间动效。
- 原简历事实完整迁入：3 段教育、2 个方向、6 个科研/教学项目、2 个服务经历、全部资质/统计/实验技能、动态公开成果/会议/教学记录。保留学生抽样调查表述，不扩大样本结论。
- 简历独立黑白/春季荧光黄视觉，季节切换改变大色块和带状边缘，深浅模式改变主展区及导航，顶部不重复四象星图；其他页面保留四季和星图。
- 便捷：原生章节锚点、记录清单、全站搜索/专注/动效开关、中英双语。打印自动展开所有记录，取消后恢复。无动画库、无滚动劫持；离屏与页面不可见暂停，减少动效优先。
- 参考独立设计实践的动效字体语汇：DIA Studio https://www.dia.studio/ （不复制作品）。字体为 Google Fonts OFL 开源字体，本地托管并保留许可。

## 简历二次方向：以动态线场取代静态雕塑（用户最新反馈优先）
用户认为第一版仅醒目，缺乏酷炫动效，要求破格，参考 JIEJOE 与 https://wodniack.dev ，保留银白/黄/黑，借鉴线条艺术、视觉效果，不照搬参考配色。
- 已用真实浏览器查看两个参考的首屏及滚动状态；Antoine 参考截图在 .impeccable/review/reference-antoine.jpg。参考的是全幅线场、结构化边界、大型字体、分段视觉节奏，不复制素材和代码。
- 全幅 SVG 实时线场：60 条空间曲线 + 24 条背景波线（手机 36 条空间曲线），原生投影与透视；持续旋转和波动，鼠标扰动，点击或键盘按钮产生传播脉冲。
- 学习阶段 2017/2022/2024 对应波面、环面、结状结构的真实几何插值，原始学习事实同期显示。抽象图形只作艺术，不表示科研模型。
- 章节跳转使用 12 片斜切幕布，0.85 秒内完成跳转并恢复；保留锚点、修改键新标签、标题焦点、返回路径；普通滚轮与触屏滚动不拦截。
- 章节之间的编织线条、教育年份和研究标题由滚动驱动，内容默认可见，支持不足时静态呈现。
- 无新增动画依赖。渲染有帧率上限，离屏/隐藏/打印时暂停；系统与手动减少动效立即停止连续更新、变形和转场，年份选择仍可用。
