# 其余四原理的轻量游戏构思

2026-10-09。已完成的对应关系是：非加和—造物实验室，有序性—有序实验室，自主性—自主实验室。以下四项为待选择的玩法方案，尚未实现。名称都沿用“xx实验室”，每轮约2–5分钟，支持点选/触屏/键盘，无需账户。

## 元整体原理：观象实验室

**一句话：局部看似正确的修补，可能让整个系统更糟。**

一只小型生态瓶正在失衡。玩家先通过有限的观察镜查看水、藻、微生物与小鱼，再切回整体图决定两次干预。镜头不是装饰：局部视角只显示所在节点，整体视角能看见物质流、延迟和上下游。每轮给不同的初始线索，避免背答案。

核心操作是选观察点→播放短时间切片→选择干预→观察全局后果。目标是在有限预算内让生态瓶连续稳定三轮，不能只把某个局部数值刷满。失败后可重放自己的操作，看到问题沿关系传播的过程。这里的生态瓶是原创简化模型，体现“从整体出发认识系统”的取向。

第一版做6个情景、4种干预和可重放记录。最有意思的时刻是玩家发现：刚才帮助了一个对象的动作，改变了另一端的条件。

## 天生人原理：共境实验室

**一句话：在不断变换的季节里，给人和环境共同留出空间。**

一张小地图包含居所、农田、林地、河流与湿地。玩家每季只能安排两项建设或维护，在春、夏、长夏、秋、冬的连续变化中同时照顾生活需求和生态条件。便利并非越高越好，建设会改变水、栖息地和下一季的承受能力。

核心操作是选择地块→安排行动→推进一季。五季结束时，要求人的生活与生态条件都在合理区间，并且没有透支到下一季。每次季节更换直接使用主页已经建立的天穹和配色语言，但界面仍以地图操作为中心。

第一版做3张小地图、6种地块、10个回合；一轮约4分钟。彩蛋可通过同时保留林地、湿地和人居来显现“人与自然”的关系图。这最能把主页的四时特色变成真正可玩的内容。

## 有机性原理：共生实验室

**一句话：养活每个成员，还要让它们的交换接得起来。**

一个微型生态瓶有生产者、消费者、分解者与循环器四种模块。每个模块既提供资源也依赖其他模块，增加某一类并不总能增强整体。玩家拖动交换关系、调整投入比例，让瓶内的三个循环持续运行。

核心操作是放置模块→连接交换→试运行→调整一项。目标是连续保持若干轮供给与消耗相称，且每个角色都参与循环。与有序实验室的“通路接通”区分：这里通了还不够，交换的量、时机和相互依存都影响结果。

第一版控制在4种模块、6个槽位、8个小关卡，单关约2分钟。特征效果是在稳定时出现一圈彼此接续的流动，而不是孤立的“最佳个体”。

## 功能性原理：异用实验室

**一句话：同一批零件，换一种组织方式，就能做另一件事。**

玩家获得轮、杆、绳、镜面、容器等固定零件，在一个小工作台上搭出完成目标的机关：把水送过障碍、让光照到指定位置、把物体移到高处。零件没有唯一用途，关卡也允许不同解法。

核心操作是选零件→放入连接点→试运转。目标用实际运行结果判定，不能靠“选对某个名字”通关。每次成功保存机关草图，下一关可能要求用同样的零件完成不同任务，凸显结构、功能和环境之间的关系。

第一版以离散连接点和有限状态模拟实现，不做复杂物理引擎：6类零件、8个任务、每个任务至少2种经过验证的解法，单关约3分钟。机关开始运转和成功交付是主要的视觉奖励。

## 建议优先顺序

若下一轮先做两个，建议“异用实验室＋共境实验室”。前者提供最直观的创造与试错乐趣；后者与作者主页的季节、长夏和中医系统论个性结合最强。观象更偏观察推理，共生更偏资源配平，可以随后扩展。

这些方案只呈现各原理的一个可交互侧面，不能代替原理的完整论述；正式制作前再与作者逐项确认概念表达和具体目标。
