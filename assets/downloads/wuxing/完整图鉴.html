公式

组合解释
阴 + 阳 → 太极阴阳相遇，点亮太极图，开放金木水火土五行，以及空气与光两项基础介质。这是游戏开篇的文化意象。
额外展开：金、木、水、火、土、空气、光
yin-yang-taiji · 文化意象
木 + 土 → 植株以木本植物枝条在适宜基质中生根为线索，省略栽培条件。
wood-earth-plant · 简化造物
土 + 火 → 金以矿石经冶炼成为金属为线索，压缩材料与加工条件。
earth-fire-metal · 简化造物
水 + 火 → 蒸汽加热让水汽化。这里用两个元素概括过程。
water-fire-steam · 简化造物
蒸汽 + 阴 → 云用阴的凉意联想到水汽冷凝，以云作为新的意象。
steam-yin-cloud · 文化意象
云 + 水 → 雨云中的水滴增长，形成降水的线索。
cloud-water-rain · 简化造物
雨 + 土 → 河流降水沿地表汇流，形成共同的河道。
rain-earth-river · 简化造物
土 + 土 → 石将土的凝聚意象进一步放大，发现石。
earth-earth-stone · 文化意象
石 + 水 → 沙水参与风化与搬运，岩石逐渐成为细小颗粒。
stone-water-sand · 简化造物
土 + 河流 → 黏土从河岸细腻的泥土，联想到可塑的黏土材料。
earth-river-clay · 文化意象
黏土 + 火 → 陶器黏土成形后经烧制，得到陶器；配方省略具体工序。
clay-fire-pottery · 简化造物
沙 + 火 → 玻璃含硅原料在高温下熔融并冷却，联想到玻璃；实际配料更复杂。
sand-fire-glass · 简化造物
植株 + 植株 → 种子以开花植物授粉、结籽的过程为线索，省略具体繁殖条件。
plant-plant-seed · 简化造物
种子 + 土 → 植株种子在适宜条件下萌发；土代表这里的生长环境。
seed-earth-plant · 简化造物
植株 + 书 → 药草通过本草记录识别具有药用传统的植物，打开本草文化分支。
plant-book-herb · 文化意象
种子 + 水 → 谷物把水分与其他生长条件压缩为一条从种子到收获的路线。
seed-water-grain · 简化造物
木 + 水 → 纸木质纤维经过制浆、抄造与干燥，成为纸。
wood-water-paper · 简化造物
木 + 火 → 墨从燃烧产生的烟炱联想到制墨；实际制墨还需要胶与工艺。
wood-fire-ink · 简化造物
纸 + 墨 → 书纸提供载体，墨记录文字，编排成书后知识可以传递。
paper-ink-book · 简化造物
金 + 石 → 针具金属经加工获得针的形制；此处概括材料与工艺的关系。
